
# Youtube Shortcodes

- To embed a single YouTube video in pages, posts, blogs, etc use the following:
    `< youtube/video ########## >`

     where `##########` is the YouTube video ID — the `v=` value in a watch URL.
     For `https://www.youtube.com/watch?v=dQw4w9WgXcQ` the ID is `dQw4w9WgXcQ`.

- To embed a whole YouTube playlist use:
    `< youtube/playlist ########## >`

     where `##########` is the playlist ID — the `list=` value in a playlist
     URL, usually starting `PL`.
